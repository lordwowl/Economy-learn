# Цепочка

Обучающий экономический симулятор для школ. Дизайн — в [`docs/GDD.md`](docs/GDD.md), ход работ — в [`PROGRESS.md`](PROGRESS.md).

## Команды
```
npm ci            # установка зависимостей (Node 22+)
npm run dev       # dev-сервер
npm test          # тесты Vitest
npm run build     # проверка типов + сборка в dist/
```

Сайт собирается и публикуется на GitHub Pages автоматически при push в `main`.
